# VaultScreen-8K — Wallpaper Prompt Batch 01

15 source posts analyzed from TikTok photo-mode carousels (and one channel sample).
Each entry: visual breakdown of the source, then a ready-to-run generation prompt that
reproduces the *style* with 1–3 deliberate swaps so it is a variation, never a copy.

**Sourcing note:** posts were pulled with `yt-dlp` (with a metadata-API fallback for
photo-mode carousels) on a runner via `.github/workflows/harvest.yml`, downscaled to
contact sheets, and read visually. No captions, on-screen text, watermarks, logos or
trademarked characters from the originals are reused in any prompt below.
